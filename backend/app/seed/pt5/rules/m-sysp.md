# Systems with a parameter
**Rule.** No solution: the lines are parallel, so the coefficients are in the same ratio but the constants are not. Infinitely many solutions: the same line, so every number (both coefficients and the constant) scales by the same factor.
**Your trap.** In a system like 5 + 3r = pw and 3r - 2w = 2w + 9, you matched numbers before you put the two equations in the same form.
**Method.**
1. Rewrite both equations the same way: use ax + by = c, or isolate the same expression (like 3r) in both.
2. Combine like terms on each side (2w + 2w gives 4w).
3. Find the scale factor from a coefficient you know.
4. No solution: make the other coefficient match and check that the constants differ. Infinitely many: the constants must match too.

**Watch for.**
- Signs change when a term moves across the equals sign.
- For "no solution", match coefficients, not constants.
- Clear fractions and decimals first.
