# Number of solutions (linear)
**Rule.** Simplify until one x term is left, or none. If x is left (like 9x = 0), there is **exactly one** solution, even when it is x = 0. If the x terms cancel, a true statement (0 = 0) means **infinitely many** solutions and a false one (0 = 5) means **no** solution.
**Your trap.** The equation became x = 0 and you answered "Zero". But 0 is a value that works, so there is one solution.
**Method.**
1. Distribute and combine like terms on each side.
2. Move all x terms to one side and all numbers to the other.
3. If an x term stays, there is one solution. If not, read what is left: true means infinitely many, false means none.
4. With a constant k: infinitely many needs equal x-coefficients AND equal constants. No solution needs equal x-coefficients and DIFFERENT constants.

**Watch for.**
- "Zero solutions" means a false statement, never the value x = 0.
- A linear equation never has exactly two solutions.
