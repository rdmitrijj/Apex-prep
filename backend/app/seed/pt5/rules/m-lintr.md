# Linear functions and transformations
**Rule.** A shift moves the graph but never changes the slope. To find *f*, undo the shift.
**Your trap.** The graph of y = f(x) + 19 had y-intercept 3. You did not undo the +19. Subtract it: f(0) = 3 - 19 = -16, so f(x) = -d - cx.
**Method.**
1. Read the slope sign from the graph or the points. It is the same for *f*.
2. Vertical shift y = f(x) + k: f(0) = (intercept) - k.
3. Horizontal shift y = f(x - h): the intercept is f(-h), so f(0) = (intercept) + (slope)(h).
4. With c and d positive: the sign in front of cx is the slope sign; the sign in front of d is the intercept sign.
**Watch for.**
- y = f(x) - 7 means f(0) = (intercept) + 7.
- A point like (2, 9) is not the y-intercept. Find the intercept first.
- f(x) = -d - cx has both signs negative, even if the order looks unusual.
