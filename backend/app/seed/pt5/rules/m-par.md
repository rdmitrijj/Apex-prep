# Parallel lines and angles
**Rule.** When a line crosses two parallel lines, each angle pair is either **equal** or **adds to 180°**.
**Your trap.** You set same-side interior angles equal. They are supplementary: they add to 180°.
**Method.**
1. Find where each angle is: between the parallel lines (interior) or outside them; left or right of the transversal.
2. Same side, both interior: add them to 180°.
3. Alternate interior (opposite sides, both interior) or corresponding (same position): set them equal.
4. Solve for x, then find the angle the question asks for.
**Watch for.**
- Check: one angle acute and one obtuse means they add to 180°.
- The question may ask for an angle, not x. Read the last line again.
