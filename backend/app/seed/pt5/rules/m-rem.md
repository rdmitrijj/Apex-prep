# Remainder theorem and expanding
**Rule.** The remainder when p(x) is divided by (x + a) is p(-a). If (x + a) is a factor, then p(-a) = 0.
**Your trap.** You plugged in the wrong sign, or, when expanding (ax + b)(cx + d), you multiplied two terms from the same bracket.
**Method.**
1. Set the divisor equal to 0: x + 3 = 0 gives x = -3.
2. Put that value into p(x). For a factor, set the result equal to 0 and solve for k.
3. To expand, multiply each term of the first bracket by each term of the second: ac, ad, bc, bd.
4. Match coefficients: x² term, then constant, then the x-term (ad + bc).
**Watch for.**
- x + 5 means x = -5, and (-5)³ is negative.
- For 2x + 1, use x = -1/2, not -1.
- Never multiply two terms from the same bracket.
