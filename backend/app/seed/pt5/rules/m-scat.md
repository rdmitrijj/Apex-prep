# Moving a line of best fit
**Rule.** Change the data, and the line changes in the same way. Start from y = mx + b.
- Every y times k: y = k(mx + b). Slope **and** intercept are multiplied by k.
- Every y plus k: y = mx + b + k. Only the intercept changes.
- Every x times k: y = m(x/k) + b. The slope is divided by k; the intercept stays.
**Your trap.** Every y was multiplied by 3.9. You changed only one number. A vertical stretch multiplies the whole right side, so the slope and the intercept both change.
**Method.**
1. Write what happens to one point: (x, y) becomes (x, 3.9y).
2. Apply the same change to the whole equation.
3. Simplify. Compare the slope and the intercept with each choice.
**Watch for.**
- The old line is always a wrong choice.
- Two steps (multiply, then add)? Do them in the order given.
- Desmos: type the changed equation, for example y = 3.9(1.5x + 12).
