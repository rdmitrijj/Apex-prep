# Cross-Text Connections
**Rule.** Text 2's author answers Text 1 with Text 2's own evidence. The answer says only what that evidence supports: it agrees, adds a condition, or disagrees.
**Your trap.** Text 1 said a method had reached its limit, and Text 2 reported a new method that worked. You picked an option that neither text discusses. The answer was simple: "progress is still being made."
**Method.**
1. Write Text 1's claim in a few words (for example, "no more progress").
2. Write what Text 2 shows (for example, "new method, high accuracy").
3. Name the relationship: agrees, true only in some cases, or wrong.
4. Pick the choice that uses only facts from the two texts.
**Watch for.**
- *Not discussed*: a topic that neither text mentions. Cross it out first.
- *Too strong*: "always", "any", "complete" when Text 2 shows only a gain or "as many as".
- *Agrees with Text 1* when Text 2's data go against it.
- *Reverses who says what*: Text 2's finding is given to Text 1's author.
